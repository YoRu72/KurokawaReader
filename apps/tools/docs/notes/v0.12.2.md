### Fixes
- **Downloads go to their own folder you can see: Download/Kurokawa.** Until now, with no folder chosen, they were kept in the app's private storage. Phone file managers can't see that storage, and it's deleted with the app. Now the app makes its own folder in the phone's Download folder and saves there. Finished files are added to the phone's media list, so the gallery and music apps show them straight away. If downloads are still in the old place, *Settings → Downloads → Move to Download/Kurokawa* moves the finished ones in one go.
- **Opening a finished download no longer says "file can't be found".** A finished torrent wasn't loaded again after the app restarted, so its files couldn't be located. They're now found from the torrent's saved description, and they're listed, opened, played and deleted as before.
- **Open opens the right file.** For a torrent of several files it opened the first in its list, even one you didn't download. It now opens the main file (the largest of the ones downloaded). In the Files list, each finished file has its own Open button.
- **Delete from device, like Flud.** Removing a download (one or several) asks whether to also delete its files from the device. Deleting the files of a finished torrent didn't work after a restart; it now does.

### New
- **Faster downloads of single files, to the end.** Like download accelerators and speed tests, every connection is kept busy: when no chunk is left, the slowest part is cut in two and an idle connection takes its second half. One slow connection no longer holds up the last minutes. In a test with one connection crawling, a 20 MB file went from 3.0 s to 0.9 s.
- **16 connections by default for a file download** (8 before). A server that refuses so many is remembered and asked with fewer.
