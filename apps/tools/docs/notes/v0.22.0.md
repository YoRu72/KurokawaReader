### Fixes
- **The Undo button on the phone can be closed** (a close control, or swipe it away), always leaves on time, and no longer covers the buttons under it. Its time waits while a sheet hides it.
- **Files no longer comes up blank.** A slow folder shows «Still reading» with Try again and Storage root; one odd file name can no longer empty the list.
- **Gestures stop fighting:** the chip strip no longer opens the drawer, a diagonal scroll no longer asks to delete a row, a tap after a short swipe is not lost, and a double tap on Paste pastes once.
- **After Android closes the page to free memory** you come back to the same folder, place in the list and copy list, with running jobs shown again. It happens at most once a minute, so a folder that keeps closing the page cannot trap you.
- **Files uses far less memory in big folders**, and a folder opens at once: item counts are read only for the folders on screen.

### New: the file browser on the phone, rebuilt
- **Compact rows:** about twice as many per screen, with the item count or size under the name and the date at the row's end. «Rows: comfortable» brings the larger rows back.
- **One header bar:** the folder's name with its path under it; tap it for the parent folders. A «..» row goes up.
- **Long-press to select**, and a bar appears at the bottom: Copy, Cut, Delete, Rename (or Archive for several), More. Drag from a long-pressed row to select the rows you pass; tapping a row's icon selects it too.
- **A paste bar** follows you to the folder you choose: «Paste here» or cancel.
- **One «More» sheet** for view, row size, sort (tap again to flip; it can be remembered per folder), hidden files, counts and thumbnails, this folder's actions and the tools.
- **Search in the folder as you type**, with sub-folders if you ask.
- **The places drawer in groups:** storages with free space, favourites you can reorder, recent folders, collections, trash and remote places.

### New: Kurokawa Tools as the file picker in other apps (Android)
- **Tools now opens its own browser** when another app asks for a file: one tap returns a file; for several, tick them and press «Add». Files that do not match what the app asked for are dimmed, with «Show all files».
- A setting chooses between **its own browser** and **storage places** (needed to save from other apps into Tools' folders, because Android only allows its own screen for saving). If other apps already use Tools' storage places, they are kept until you switch.
- In storage-places mode there is one «Kurokawa Tools» entry instead of two, with a Recent list.

### New: the file browser on the computer
- **A details list** with Name, Size, Type and Date modified: click a heading to sort, drag its edge to resize, right-click to hide a column.
- **A navigation pane:** quick access, favourites, recent folders, drives with free space, and a folder tree. Ctrl+B hides it.
- **An address bar:** click a part of the path, open a part's sub-folders from its arrow, or press Ctrl+L and type a path. Back, Forward and Up with history (Alt+arrows, the mouse's side buttons).
- **A status bar** with the item count and the size of what is selected.
- **Keyboard and mouse:** type to jump to a name, Shift and Ctrl selection, drag a box to select, F2 renames in place, Delete to the bin and Shift+Delete for good (it asks), a right-click menu on empty space. With two panes, keys go to the pane you last clicked.
