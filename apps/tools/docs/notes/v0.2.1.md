### Fixes
- **Add-on sources failed on the device** — every search chip showed a warning. The add-ons' code is fetched from GitHub, which labels it as plain text, and the phone refused to run it as a module; it is now stored as JavaScript (already installed add-ons are fixed on load too).
- Arabic: the schedule's times no longer wrap (24-hour clock), episode counts use one set of digits, «بُثَّت» for aired episodes.
- The downloads page says plainly that nothing has been downloaded yet when the list is empty.
- A page that fails to draw now shows what went wrong (and a retry) instead of staying blank.

### New
- **Layout direction** in Settings: by language, left to right, or right to left — as in the reader.
- **Debrid** add-on: Real-Debrid, AllDebrid, Premiumize and TorBox. A magnet, .torrent or hoster link goes through the service («Through Real-Debrid» in the add sheet, or by default from Settings → Downloads), the cloud fetches it and the app downloads the files at full speed; a Cloud button on the downloads bar shows the account's transfers and torrents.
