### Fixes
- **No more red «e.addListener(...).catch is not a function»** on the Downloads page (Android). Android's own Back handler answers without a promise, and the app expected one. Back now works the same and the message is gone.
- **Updates no longer stall on a busy network.** A download that drops is tried again (three times). One that arrives damaged is refused, not installed.

### New
- **The player takes REX Player's and VLC's features** (the Player add-on).
  - **Gestures:**
    - Choose what a double tap does on each side and in the middle: seek, play/pause, previous/next chapter, or nothing.
    - Taps add up: +10, +20, +30 s, shown on that side.
    - Volume can go on the left, and you set how far a swipe seeks.
    - While holding for fast speed, slide sideways to change it. The held speed can be remembered.
  - **Seek bar:**
    - A preview of the frame under your finger while dragging.
    - Bookmarks marked on the bar.
    - A clock on top, and how long the controls stay is yours to set.
  - **Playback:**
    - Jump to a time.
    - Repeat one or all, and a playlist to pick from.
    - Close at the end, or play on in the background.
    - Frame steps at the video's own frame rate.
    - Speed in 0.05 steps, and any speed can be made the default.
    - The system's media controls.
    - Play on another screen where the system offers it.
    - Sound only (picture off).
  - **Sound:**
    - VLC's 10-band equaliser with its presets (Rock, Pop, Classical, Headphones, Large hall…) and a preamp.
    - Loudness evened out (a night mode), mono, left/right balance, and the sound delayed against the picture.
    - The video's audio tracks, where the system lists them.
  - **Picture:**
    - Rotate, mirror or flip, and crop to 16:9, 2.35:1 and others.
    - Gamma, sharpness and colour temperature next to brightness, contrast, saturation and hue.
    - Looks: Vivid, Cinema, Warm, Cool, Anime, Night, Black and white…
  - **Subtitles:**
    - Outline colour and width, italic, background opacity.
    - A second track on top, with its own height and size.
    - Timing stretched for a file made for another frame rate.
    - Line-by-line seeking (Ctrl+← / →).
    - VLC's two-tap sync: tap «Heard» when a line is spoken, «Shown» when its subtitle appears.
  - **VLC's keys** on a computer: g/h subtitle delay, b audio track, c crop, r rotate, n/p next/previous, t time, 0–9 to jump, Shift+B bookmark.
  - All the player's preferences are also in Settings, grouped like REX Player's: Gestures, Controls, Playback, Subtitles, Sound, Picture.
- **Settings by add-on.** A bar of tabs at the top: All settings, The app, then one tab for each installed add-on, with its own cards and its sources' options together. Prefer the old way? Settings → General → Settings layout → One list.
- **A better app installer:**
  - It shows the Android version the app needs and targets, the processors its code is built for, what it can access (sensitive permissions marked) and who signed it.
  - If the app is not built for this phone's processor, you are told before installing.
  - If an update is signed by someone other than the installed copy, Android would refuse it, so the installer says so and offers to uninstall that copy first. The same offer appears after such a failure.
  - A bundle's languages and screen sizes can be left out.
  - A game's data (OBB) is put where the game reads it. Where Android does not allow that, it is saved to Download/obb with a note on where to move it.
  - After installing: Open, or App info.
- **A better updater:**
  - It lists what's new in every version since yours, not only the latest.
  - The download is checked against the SHA-256 GitHub states for the file.
  - If the system asks you to allow installing, the install carries on by itself once you do.
  - A download you already have is installed without fetching it again.
  - It still works when GitHub limits its API (through the releases feed).
  - Check every launch, daily or weekly, and optionally download updates in the background.
  - The first start after an update says so, with what changed. Earlier versions' notes are one tap away in Settings → Updates.
