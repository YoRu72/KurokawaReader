### Fixes
- **MKV with a black picture (computer)**: many anime releases use video the computer's built-in player can't show (10-bit H.264, HEVC without a graphics card that decodes it, XviD, MPEG-2, WMV…), so you got sound over a black screen, or nothing at all. The player now sees this, either from the file's details or from a video playing with no picture, and has ffmpeg convert the picture as it plays. It uses the graphics card's encoder when one works (NVIDIA, Intel, AMD, Apple) and the processor otherwise. Seeking, the time bar, sound tracks and subtitles work as usual.
- **Black picture on a phone**: if the built-in player shows no picture, the video now reopens in mpv at the same spot (fetching mpv's pack first if needed).
- **Deleting an episode deleted the whole batch**: on the anime and TV pages, «Delete the download» on an episode that's one file of a batch or season pack now asks: only this episode, or the whole download?
- **The torrent's folder doubled in file paths**: finished files of a multi-file torrent were looked for under the torrent's folder twice. Playback quietly fell back to streaming, and sharing or opening some files failed. Fixed.

### Choosing a torrent's files
- **Every torrent with several files now asks which ones first**: from the anime page, TV & Movies and the general search, not only for batches. A torrent with a single file goes straight in, with no extra step.
- **Select all / Deselect all**: one box above the list ticks or clears everything (partly ticked when some are), plus «Deselect all» among the quick choices.
- **No waiting**: while a magnet's file list loads, «Download it whole» already works. Once you've chosen, the button says how many: «Download selected (3)».

### Deleting one file
- **A trash button on each downloaded file** in a torrent's file list. That file goes to the trash and is left out of the download, so it isn't fetched again. The other files stay.

### Anime
- **You stay on the show's page**: downloading a release, a range of episodes or an online stream no longer jumps to Downloads. It downloads in the background, as in Hayase, and the message has a «Show» button if you want to see it.
- **Watch never goes to debrid**: with «send to debrid by default» on, «Watch» used to send the release to the debrid service and leave the page. Watching now streams; debrid is for downloading.
- **Faster search**: «Watch» and «Download the best» start as soon as a well-seeded release that surely matches is found, instead of waiting for the slowest site (up to 35 seconds on a bad day). The rest finish in the background.
- **Results kept for 10 minutes**: reopening the same episode's releases is instant.
- **HEVC releases no longer hidden** on a phone that has mpv, or on a computer (both play them now).
- **Dead releases last**: a release nobody seeds goes after every one somebody does, since it wouldn't stream. SeaDex's best stays on top.
