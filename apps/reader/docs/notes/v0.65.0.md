
## Fixed

- **Furigana: «The dictionary is on the device but could not be loaded».** On the phone the Reader looked for the downloaded dictionary at the wrong address, so it never loaded, and *Remove and download again* met the same fault. It now finds the files it keeps, also when they arrive already unpacked. After every download the dictionary must read a test word correctly before it is called ready; if it cannot, the files are removed and the notice says why.
- **PDF: the long blur after zooming.** A zoom used to redraw the whole page several times over before it turned sharp. Now the part on screen is drawn first and the rest follows, the sharp picture stays underneath until the new one is ready (no blank bands), and nothing is drawn while the fingers are still moving. Deep zoom uses less memory.
- **The floating Undo** has a close button, can be swiped away, leaves by itself (the timer waits while it is touched), hides behind an open sheet and stays above the bottom bar.
- **Notices no longer cover the reading controls** (the dictionary notice sat on the previous / next page buttons).
- Small buttons, chips and the PDF bar's controls are larger under the finger on touch screens; several button rows have equal widths; the last plain checkboxes (search, delete dialog) are switches; number boxes no longer show the browser's own arrows; three Arabic texts used Eastern digits; a PC label spoke of an edge swipe.
- The first three pages of a PDF kept a loading shimmer running off screen.

## New

- **Tags can be pinned** from their long-press menu, like folders and series; pinned tags come first.

## Faster

- **A quicker start.** Only the language in use and its font are loaded first, updates and sync wait until the library is shown, the reading screen's styles load with the reading screen, and a request that failed on every start is gone. In a slowed-down test the library was usable about a quarter sooner in Arabic and a tenth sooner in English.

## Not checked on a real phone

- The dictionary fix was run against the real analyser here, not on a device.
- PDF zoom: the time to a sharp page was measured in a slowed-down test (0.2–0.7 s after a pinch, from 1.3–7.3 s). How smooth the pinch itself feels can only be judged on the phone.
