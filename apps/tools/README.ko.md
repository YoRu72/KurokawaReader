# Kurokawa Tools

[English](README.md) · [العربية](README.ar.md) · [日本語](README.ja.md) · [中文](README.zh.md) · [Kurokawa 앱](../../README.md) 가운데 하나 ([KurokawaReader](../reader/) 옆)

다운로드, 토렌트, 동영상 사이트, 애니메이션, 자막, 압축 파일, 플레이어를 하나의 앱으로. Android · Windows · macOS · Linux · 웹.

- **하나의 추가 창:** 링크(여러 개, `[001-100]` 범위도), 마그넷, .torrent 파일, 동영상 사이트 페이지(yt-dlp: 화질·오디오만·자막·재생목록, 자동 업데이트). ZIP은 받기 전에 내용을 봅니다.
- **Prism 방식:** 파일당 여러 연결, 조각 지도, 속도 그래프, 기록, 범주와 폴더, 예약, 클립보드 감시, 페이지 링크 모으기, 체크섬 검증, ffmpeg로 변환과 크기 줄이기.
- **토렌트 검색:** AniList와 IMDb의 작품을 표지와 함께 보여 주고 릴리스를 작품별로 묶습니다(Knaben, The Pirate Bay, Nyaa, YTS, EZTV, Torrentio).
- **애니메이션:** AniList 추적, 시즌 표, 방영 일정, 상태별 목록. 내장 소스나 **Seanime·Hayase·Stremio 확장 기능**(앱 안 마켓)으로 에피소드 찾기. 범위 다운로드, 필러 제외, 새 에피소드 자동 받기.
- **자막:** 9개 사이트를 한 번에 검색. 애니메이션 화수를 IMDb 시즌·화수에 맞춥니다.
- **압축 파일(HatchZip 방식):** 공간 계획, ZIP과 tar 제자리 풀기(이어서·포기 후 복원), 테스트, 먼저 검증, .sfv 검사, 위험한 압축 파일 거부.
- **앱 설치(Android):** APK와 분할 번들(.apks / .xapk / .apkm)을 파일에서 바로 설치.
- **플레이어:** REX Player 제스처, A/B 자르기(자막 입히기), 온라인 자막, 오프닝·엔딩 건너뛰기(AniSkip·챕터), 화면 필터, 앰비언트, PIP.
