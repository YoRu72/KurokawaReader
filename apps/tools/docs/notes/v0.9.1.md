### Fixes
- **Updating from inside the app works again** (Android). Since 0.8.0, «Download and install» stopped at once with «Prefix string too short»: the downloader gave its temporary progress file a name Android refuses. Updates from 0.8.0 or 0.9.0 still have that fault, so install this version once from the release page; from 0.9.1 on, updates install from inside the app again.
