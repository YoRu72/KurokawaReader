# KrDoh.java (phone), desktop/dohchain.cjs (Electron) and src/dohProviders.ts (the settings page) carry copies that
# tests/dohchain.cjs checks against this file, field by field. No resolver that needs an account or a key.
# id|label|address (RFC 8484)|bootstrap addresses (the resolver reached by these, never by the network's DNS)|json|filters
# json: «json» when the provider documents the JSON form (GET ?name=&type=) as well; filters: what it blocks by
# itself (none, malware, ads, phishing, legal = court-ordered blocks only). Sources, read 2026-11-16:

#  dnssb       dns.sb/doh/ («pure IP DNS over HTTPS»: https://185.222.222.222/dns-query — the address itself is the
#              name checked, so no CDN name is guessed; its IPv6 form is a different address, left out)
#  controld    docs.controld.com/docs/free-dns (Unfiltered, no account)
