### Fixes
- **A file name with a colon in it unpacks on Linux and macOS** (for example «meeting 10:30.txt»). On Windows a colon is still refused, and a name that begins with a drive letter is refused on every system.

### Under the hood
- **The code that draws themes is now shared with Kurokawa Tools in a cleaner way.** Nothing changes in how the Reader looks or behaves. A theme made in Tools that has an animated background opens in the Reader as a still picture.
- **The Reader's own checks were tidied:** one measurement that used to fail on a busy machine is no longer listed as a known failure.
