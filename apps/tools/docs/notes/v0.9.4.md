### Fixes
- **The crash report shows where the app crashed** (Android). The report of a native crash used to show only the first lines of Android's record, which were threads that were waiting, not the one that crashed. Android's record is now read properly. The report shows the signal and its cause, then the thread that crashed with each step of its stack (library and function), then the other threads by name, then the app's last log lines before the end. Copy it from the card and send it.
- **A safe start after repeated crashes.** If the app closes within a minute and a half of starting twice in a row, the next start keeps the torrents paused and the torrent engine off. The app can then be opened and used. Resume the torrents one by one: if the app closes right after one is resumed, that torrent is what ends it.
