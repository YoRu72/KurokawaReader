### Fixes
- **Windows build:** the aria2c archive is now unpacked by the app's own build script instead of the system `tar`, which failed on the build machine — so the Windows installer and portable EXE are published for the first time.

### Add-ons
- **Torrent search** — the first add-on group, from Settings → Add-ons: **Nyaa** (anime torrents, seeders first) and **Torrentio** (films and series by name through IMDb, with your debrid service's cached links when you give it the key; write «S01E02» after the name for an episode).
- **Add-on settings:** an add-on that needs anything from you (a key, a choice) gets a gear on its row that opens its settings.
- Add-ons reach the web through the app itself on Android and the desktop (no browser cross-origin limits).
