### Fixes — keeping your data safe
- **Keys and passwords no longer go into backups.** AI keys (including custom APIs' keys and headers) and sync passwords were written into backup files. They are now left out of every backup, and the automatic backups already stored on the device are cleaned. **If you shared or uploaded a backup made before this version, change those keys** — the old file still holds them. A custom API restored from a backup arrives without its key; enter it again.
- **"Select all" under a search or filter** chose every book in the library, not only the ones shown, so deleting removed books you could not see. It now takes only what is listed, and books that leave the list leave the selection. The delete question states the count and that it cannot be undone.
- **Changes made at the same moment no longer overwrite each other**: a book's details, lists of tags and folders, saved web-novel chapters, and the marks that keep erased ink strokes from coming back through sync.
- **Deleting a book no longer touches another book's data** when their internal names begin alike; and a deleted book's glossary, text rules and settings go with it.
- **Moving a book out of the app** no longer overwrites a file of the same name (it is saved as «name (2)»), and the app's copy is removed only after the written file is checked.
- **Restoring a backup** no longer moves your reading position backwards: the later position is kept. Notes, highlights, bookmarks, glossary and rules are merged; nothing on the device is deleted.
- **Backups are complete**: ratings and reviews, chapters read and marked, series, the book's own settings, Anki progress, the audiobook place, text rules and saved words are now included. Older backup files still open.
- Incognito reading no longer adds time to reading statistics.
