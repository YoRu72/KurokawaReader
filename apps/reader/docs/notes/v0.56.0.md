### Fixes
- **The beta channel could offer a Kurokawa Tools release as a reader update.** Both apps publish in the same repository, and the beta check took the newest release of either. It now only looks at the reader's own releases.
- **Updates no longer stall on a busy network.** A download that drops is tried again (three times). One that arrives damaged is refused, not installed.

### New
- **A better AI translator:**
  - **Show the original too.** Choose this to put the translation under each paragraph, with the original dimmed above it. Switch from the eye button on the translator's bar.
  - **Italics and bold come through** the translation.
  - **Context with each request.** The model is given the book, the chapter and the two paragraphs before, so names, pronouns and tone carry on from one batch to the next.
  - **Paragraphs already in your language are left alone** (Arabic, Persian, Urdu, Japanese, Chinese, Russian), which saves time and tokens.
  - **The next chapter is translated while you read**, so it opens already translated.
  - **Find names for the glossary.** The model reads the chapter and proposes its names and terms with renderings. Tick the ones to keep, correct any, and add them for this book or every book.
  - **Sturdier.** A busy or rate-limited provider is waited for and asked again. A reply that loses a paragraph is asked for again in halves instead of failing the whole batch.
  - **Requests at once** (1–6), for faster translation when your provider allows it.
- **A better updater:**
  - It lists what's new in every version since yours.
  - The download is checked against the SHA-256 GitHub states for the file.
  - It still works when GitHub limits its API (through the releases feed).
  - Android can download updates in the background and offer them ready to install.
  - The first start after an update says so, with what changed.
