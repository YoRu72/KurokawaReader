# Kurokawa Tools

[English](README.md) · [العربية](README.ar.md) · [中文](README.zh.md) · [한국어](README.ko.md) · [Kurokawa アプリ](../../README.md)の一つ（[KurokawaReader](../reader/) の隣）

ダウンロード、トレント、動画サイト、アニメ、字幕、アーカイブ、プレーヤーをひとつのアプリに。Android · Windows · macOS · Linux · Web。

- **ひとつの追加欄:** リンク（複数や `[001-100]` の範囲も）、マグネット、.torrent、動画サイトのページ（yt-dlp：画質・音声のみ・字幕・再生リスト、自動更新）。ZIP は中身を見てからダウンロード。
- **Prism 流:** 1ファイルに多数の接続、ピースのマップ、速度グラフ、ログ、カテゴリとフォルダー、スケジューラー、クリップボード監視、ページのリンク収集、チェックサム検証、ffmpeg による変換とサイズ縮小。
- **トレント検索:** AniList と IMDb の作品をカバー付きで表示し、リリースを作品ごとにまとめます（Knaben、The Pirate Bay、Nyaa、YTS、EZTV、Torrentio）。
- **アニメ:** AniList の追跡、シーズン表、放送スケジュール、ステータス別リスト。内蔵ソースや **Seanime・Hayase・Stremio の拡張機能**（アプリ内マーケットから）でエピソードを検索。範囲ダウンロード、フィラー除外、新エピソードの自動取得。
- **字幕:** 9 つのサイトを一度に検索。アニメの話数を IMDb のシーズン・話数に対応付け。
- **アーカイブ（HatchZip 流）:** 容量の見積もり、ZIP と tar のその場展開（再開・元に戻すも可）、テスト、先に検証、.sfv 検査、危険なアーカイブの拒否。
- **アプリのインストール（Android）:** APK と分割バンドル（.apks / .xapk / .apkm）をファイルから直接インストール。
- **プレーヤー:** REX Player のジェスチャー、A/B 切り出し（字幕焼き込み）、オンライン字幕、OP/ED スキップ（AniSkip・チャプター）、映像フィルター、アンビエント、PiP。
