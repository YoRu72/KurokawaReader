### Fixes
- An archive whose files would land outside the chosen folder, or that lists the same file twice, is now refused before anything is touched.
- A file cut short by a cancelled extraction no longer stays behind as a `.part`.

### Changes
- The "Other Kurokawa apps" section is gone from Settings.

### New — Archives, the HatchZip way
- **A space plan before anything changes:** free space at the destination, what a normal extraction needs, what an extraction in place needs (its largest file plus a margin of 2 GB on a computer, 512 MB on a phone that is never used), and what is left after. When only in place fits, it is chosen for you; when nothing fits, nothing starts.
- **tar archives extract in place** too, besides ZIP, and resume after a stop.
- **Give up and restore:** a half-done extraction in place can be abandoned; what is left of the archive becomes a normal archive again, holding exactly the files not yet extracted.
- **Test** reads every file and checks it without writing anything; **Verify first** does the same before an archive is cut, for downloads that cannot easily be fetched again; an `.sfv` file beside the archive is checked first.
- **Extract here** puts a single top-level item beside the archive and several into a folder named after it; files already there are counted, and kept side by side by default.
- **Several archives** can be picked at once; they are extracted one after another, each checked for space as it starts.
