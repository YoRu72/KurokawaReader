### Files — a new add-on
A file manager in the shape of Solid Explorer, made for a downloader (its features studied, with ZArchiver's, in `docs/research/file-managers.md`):
- **A drawer** (the ☰ button): the storages with their used space, your bookmarks (the + button bookmarks a folder), and **collections** from the phone's media index — Recent files, Images, Music, Video, Documents, Archives, Apps — the recent ones under day headers (Today, Yesterday, the date).
- The title says what the folder holds («1 folder, 6 files»); a grid of round tiles by default (the list a tap away); a + button for a new folder, paste, a bookmark.
- **Storages**: the app's folder, the phone, SD cards and USB drives, each with its free space; the whole phone once «All files access» is allowed (asked for from the page).
- **Browsing**: breadcrumbs, a list or a grid (pictures, video frames and app icons as thumbnails, read lazily), sort by name / date / size / type (tap again to turn it round; folders first), **filter by kind** (images, music, video, documents, archives, apps), hidden files, a search within the folder, folders with their item counts.
- **Opening**: a tap opens in the app — video and sound in the player, archives as folders (with Extract here / Extract to…), apps in the installer, text with a quick look; **Open with…** any app, **Open as…** a kind (image, music, video, text, document, archive, any); Share.
- **Operations**: hold to select (all, invert), then copy / cut / paste, delete, rename, zip, share, properties; new folder. Copy, move and delete run as **jobs** with bytes and files counted, cancellable; **a name already taken asks**: skip, keep both («name (1)»), replace — for one or for the rest. A move on the same storage is a rename, instant.
- **Properties**: size (a folder's counted whole, with its files and folders), modified, kind, access; copy path.
- **Kurokawa Tools in every app's file picker**: a documents provider — the app's folder (and the phone when allowed) under «Kurokawa Tools» in any app's Open / Save / Attach picker, with thumbnails, search, new folders, rename, delete and move from there.
- **«Kurokawa Tools · Save to device»** in every app's share sheet: files shared from any app (one or many) are saved into the folder you choose.

(What is still to come from the two apps — search filters by size and date, recycle bin, batch rename, the storage analyzer, checksums/EXIF, an editor and image viewer, two panes, network and cloud storages, servers, encryption, root — is listed as tasks and comes in batches.)
