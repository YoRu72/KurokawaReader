### Fixes
- **The crash while downloading torrents is fixed** (Android). Thanks to the report from 0.9.4 it was found exactly: when a torrent was added (or restored on opening the app), the engine kept a handle that pointed into a message libtorrent frees right after. A moment later the page asked for the download list, the engine read through that freed handle, and the whole app closed (SIGSEGV in `torrent_handle::is_valid`). The engine now keeps the session's own handle for each torrent. Torrents that were kept paused by the safe start can simply be resumed.

### New
- **Install an app straight from any archive** (Android). An APK or a split bundle (.apks, .xapk, .apkm) inside a ZIP, 7z, RAR or tar is streamed out of the archive into Android's installer, the HatchZip way: nothing is extracted first, so it needs no room for a copy. This works for password-protected archives too (the password is asked), and for a bundle inside an archive (an .xapk inside a .7z, say). Split APKs lying together in a folder install as one app. Of the processor-specific parts, only those for this phone's processor are installed.
- **Several apps in one archive:** you are asked which one to install.
- **Room checked first:** if the phone may not have space for the install (about twice the app's size), you are told before it starts.
- «Delete the archive once installed» removes the archive after a successful install.
