### Fixes
- **Watch now goes on in the release you picked before.** When you chose a batch for a show (to watch or to download), Watch now plays the next episode's file from that same batch instead of looking for a new release. The episode sheet says which release it goes on in. A download already holding the episode, a batch included, is played from there, with its other files left as they were.
- **"Nothing found" is no longer the end of Watch now.** The card offers Choose a release, where you can search by any name.

### New
- **Choose a release to watch.** In an episode's sheet, the releases from every source to pick from, searched by any name like for downloading. The one you tap plays while it downloads. The list button picks one file of a batch first, and the release is remembered for the next episodes.
- **Releases are tagged and ranked like in Hayase and Seanime.** Each release shows its tags: SeaDex best, Batch, BD or WEB, HEVC/AV1/AVC, 10-bit, HDR, Remux, Dual audio or Dub, Multi-subs, Uncensored, v2. Among releases that fit your choices equally, the best-looking one comes first: SeaDex's pick, then Blu-ray and fixed versions, then seeders (a release with no seeders goes last).
