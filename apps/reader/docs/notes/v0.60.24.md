### Fixes — sync between devices
- **Folders no longer come back.** A book taken out of a folder on one device, or a folder deleted or renamed, was restored by the next sync from another device. The later move now wins, and a deleted folder stays deleted.
- **Reading time from every device is counted.** Reading the same book on two devices on one day kept only one device's minutes. Each device's time is now kept apart and added up; syncing again adds nothing twice. (Time read before the first sync on this version is merged as before.)
- **Web novels match across devices.** Progress, notes and highlights of a web novel were tied to the book's size, which changes with every new chapter, so devices rarely matched and the sync file filled with leftovers. Novels are now matched by their source; older sync data and older backups still attach.
- **Two copies of the same file** no longer share one set of notes.
- **A device whose clock runs ahead** no longer drags every other device back to its own older reading position.
- Changes made while a sync is running are no longer lost.

### To know
- Update the app on all your devices. A device still on an older version keeps working with the same sync file, but it still has the old faults on its own side (it may keep a folder deleted elsewhere, and count reading time the old way).
