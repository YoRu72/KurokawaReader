### Fixes
- **Back inside a Videos folder goes up one folder.** It used to jump to the Downloads tab and leave the folder open behind it. The same holds for folders on a server.
- **Thumbnails of videos, pictures and GIFs appear again on phones.** The app was asking Android for the wrong item, so every row fell back to the film icon. A thumbnail once made is kept on the phone, so a long list fills in quickly the second time.
- **«Save here» on the «Save to device» sheet no longer answers «e.links is not iterable».** The note that a file had been shared in was being read as a page's list of links. The sheet's row is tidier too: one line, the name shortened in the middle so its ending (.ass, .mkv) stays in sight, the size at the end.
- **Back now does the expected thing everywhere.** Each of these was wrong before:
  - a search typed in Videos: Back clears the search instead of leaving the folder;
  - a selection or an open search in Downloads: Back leaves it instead of warning «press again to exit»;
  - the open + menu: Back closes it;
  - the player in full screen: Back leaves full screen instead of closing the player;
  - the locked player: Back shows the unlock button instead of closing the player;
  - a search typed in Settings: Back clears it;
  - at the top of a tab, Back returns to the tab you came from, and never round in a circle.
- **The search box in Videos is no longer squeezed** by the sort menu beside it.
- **Speed limits** could be read as zero on some phones for the same reason as the thumbnails; fixed.

### New: one Back for the whole app
The phone's Back button and gesture, the arrows on the pages, the mouse's back button, Alt+← and Esc now all pass through one place, in one order: what is open on top closes first (a sheet, a menu, a dialog), then full screen, then a selection or a search, then the folder you are in, then the page, then the tab. On a computer, **Esc only closes what is open**; it never leaves a page or a tab.

### New: full screen by turning the phone (phones only)
- **Turn the phone on its side while a video plays and it fills the screen; turn it upright and it returns.** *Settings → Player → Full screen by turning*, on by default; turn it off if you prefer the button alone.
- If you leave full screen yourself while the phone is on its side, it stays out until the phone has been upright once.
- **The full-screen button turns the screen to suit the video:** on its side for a wide video, upright for a tall one, and back as it was when you leave.
- Sheets opened over the player (subtitles, sound, speed) now show in full screen as well.

### New: choose files with Kurokawa Tools from other apps (phones only)
- **When another app asks you to choose a file, Kurokawa Tools is now one of the choices**, beside your other file managers. It opens its own chooser: your storages, the folder path, the kinds (pictures, videos, music, documents, archives), search, sort, list or grid, with thumbnails.
- **One file or several**, as the asking app allows. What you tick is kept as you move between folders; a bar at the bottom shows the count with **Cancel** and **Select**.
- Kinds the asking app did not ask for are dimmed.
- Back goes up a folder, then cancels.
- Saving a file *from* another app into Kurokawa Tools still goes through Android's own «Save to» screen, where the app already appears.

### On computers
- **Files shows thumbnails** for pictures, videos and GIFs for the first time.

### What we ask you to try
These parts were built and tested on a computer and need a real phone:
- **The chooser:** from another app (a chat, an editor), attach a file and pick Kurokawa Tools; choose one file, then several, then a file on the memory card; press Back and Cancel.
- **Thumbnails** in Videos and Files, after a fresh start and again after reopening.
- **Turning the phone** during a video, with the phone's own auto-rotate both on and off.
- **Back** in each tab, with the gesture and with the button.
