### Fixes
- **MEGA links now download.** Before, a mega.nz link was treated like an ordinary web page, and the "download" was MEGA's page or a file that wouldn't open. The app now reads the link with its key, asks MEGA for the file, and decrypts it as it is written. Pausing, resuming and multiple connections all work as with any other download.

### MEGA
- **File links**: the Add sheet shows the file's real name and size before you start.
- **Folder links**: every file in the folder is listed, subfolders included, with a "select all" checkbox. Untick what you don't want. The chosen files are saved inside a folder named after the shared folder, keeping its subfolders.
- **Links on a page**: the grabber finds MEGA links on a page even when they're plain text instead of links, and keeps their keys (the part after `#`). They're listed under their own MEGA kind.
- **Old link addresses**: a MEGA download address expires after a while. When a paused or failed MEGA download resumes, it gets a fresh address and continues from where it stopped.
- Clear messages for a missing key, a wrong key, a removed file, and MEGA's transfer limit.
- On a computer, the file is decrypted when the download finishes.
