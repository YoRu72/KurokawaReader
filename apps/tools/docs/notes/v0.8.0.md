### Fixes
- On a phone, a paused download, or one stopped when the app closed, now continues from where it stopped instead of starting over. The server is asked first whether the file is still the same; if it has changed, the file is downloaded afresh.
- A server that allows only a few connections no longer makes the download fail: the extra connections step back, the rest carry on, and next time that server is asked for no more than it accepts.
- The Arabic grabber buttons count correctly («أضِف المحدَّد (ملفان)»).

### New — from Prism
- **AI models from Hugging Face** (+ → AI models):
  - Find a model by name, link or search, or browse what is trending.
  - Its files are listed with their sizes, and the ones worth downloading are already ticked. A GGUF model's versions can be swapped with a tap, with the vision file when it has one.
  - Files go to Models/<owner>/<name>, as LM Studio and llama.cpp expect. Each comes over several connections from the same version of the model, and is checked against its SHA-256 when done.
  - A Hugging Face link pasted in Add offers the model window. Settings → AI models holds the server (or a mirror), an access token for gated models, and the folder.
- **Settings → Connection:**
  - How the app introduces itself to servers: itself, a browser, or your own text.
  - How many times a piece is tried again, and how long a silent server is waited for.
  - A proxy (http or socks5).
  - What to do when a file of that name is already there: keep both, replace it, or skip it.
  - On a phone, the servers that refused connections are listed, and can be forgotten.
- **Recently removed** (Downloads → ⋮): downloads taken off the list are kept for a month and put back with a tap.
- **Remove the ones whose files are gone** (Downloads → ⋮): finished downloads whose files were deleted elsewhere leave the list.
- **New address…** for a download whose link ran out: paste a fresh link to the same file and it carries on from where it stopped.
- **Download again** a finished or failed download.
- **A queue:** on a phone, no more file downloads run at once than set in Settings; the rest wait their turn. A download can be moved up, down, to the top or to the bottom, and the list can be sorted in queue order.
- **The grabber follows links:**
  - Up to three levels of a site's pages, only those under the starting folder if you like.
  - A page, its depth and the kind of file you want can be kept as a project and run again.
- **Mini window (computer):** a small window above the others with the speed, what is downloading and how far along each one is. From it you can pause or resume everything and go back to the app. It can also open by itself when the app is minimized.
