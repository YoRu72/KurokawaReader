### New
- **Linking AniList without knowing an ID.** A single *Link AniList* button opens a short guide:
  1. Open AniList's developer page (inside the app).
  2. Create a client: the name and the redirect address are shown with Copy buttons.
  3. Open the client you made: the app reads its ID from the page by itself. You can also paste the ID, or the client's link (the number is taken from it).
  4. Sign in on AniList: the app picks up the token from the page AniList ends on, so there is nothing to copy.

  On the web, AniList opens in a tab and you paste the token it shows. The app is ready for a client of its own, so that it can become a single *Sign in with AniList* tap, as in Mihon.
