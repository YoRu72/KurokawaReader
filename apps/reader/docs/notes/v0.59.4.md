### Fixes
- **English names no longer leak into Arabic.** Each glossary term now belongs to a language. A rendering written for English is used only when translating into English (or another Latin-script language), never into Arabic, even when the name is found in the text.
- **No more duplicate terms.** The same name is kept once per book, folder and language. A term you wrote yourself always wins over one the translator found on its own; the auto glossary no longer adds a name twice.

### New
- **Glossary folders.** Gather names into folders (one per series, say) and use a folder with any book you like. Rename or delete folders, move terms between them, or turn a book's names into a folder in one tap.
- **Where new names go.** For each book, or as the default for every book, choose where the translator puts names it finds: the book itself, a folder made automatically from the series title, or a folder you pick. A switch decides whether new names are added there or only the folder's existing names are used.
- **Scan a whole book for names.** From the translator's ⋮ menu, the glossary can now read the whole book in the background and collect its characters and places, ready to edit.
- **Filter the glossary.** Search terms, show them by kind (characters, places, others), and include or exclude languages with the language chips.
- **Search Shamela's books for a word.** Select a word in any book and choose "Search Shamela's books for it" to find it inside every book in Shamela. The Shamela search also gains a quick switch: Books and authors / Inside the books.
