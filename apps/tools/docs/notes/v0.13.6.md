### Fixes
- **Installing an app picked in the app no longer closes the app.** An APK picked with the app's file picker was handed whole to Android's reader where it lay; on some phones (seen on Android 16) a file on shared storage could not be read that way, and the app crashed. A plain APK is now read the same way as bundles: only its manifest and resources are read out (a few MB, by seeking, without copying the app), and who signed it is read from its signing block where it lies. A large game is read in about a second, and no space is taken for a copy.
- **Downloads get the right file type.** Some sites send every file as «application/octet-stream» or name it «file.bin». When a download finishes, its first bytes are now read to tell what it really is, and a meaningless extension is put right:
  - apps: APK, XAPK, APKM, APKS;
  - documents: EPUB, Word, Excel, PowerPoint, PDF;
  - archives: ZIP, 7z, RAR;
  - media: MP4, MKV, WebM, MP3, FLAC, Ogg and others;
  - images and torrents.
  A name you gave, or a real extension, is never changed.
- **«Get a new link by itself» no longer stops on the first page.** The replay opened the page you started from and then did nothing. It now gets there:
  - Taps are recorded as soon as a page shows, not only once it has finished loading. Download sites that keep loading ads were tapped through unrecorded, so their steps were missing.
  - When a page's address differs from the one recorded (the site moved you, say from `example.com` to `www.example.com`, or the page has a new key each visit), the next buttons on the way are looked for on it anyway, in order.
  - A page that never finishes loading still has its step replayed once it is mostly there.
  - A step is never tapped twice.
  - If no step is left to take on a page, a message says so, so you can go on by hand.
  - The way kept is now up to 30 taps long (it was 12).

### New
- **Install progress in percent.** After the app is handed to Android, the installer now shows Android's own progress (checking and preparing the app) as a percentage, instead of a full bar that stood still.
