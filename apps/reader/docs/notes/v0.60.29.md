### Fixes — the glossary follows the language you translate into
- **Names come out in your language.** Translating into Arabic could keep names in English: the name finder saved an English spelling as the "Arabic" name, and the glossary then forced it into the translation. This holds for every language now: a name is used only when it is for the language you translate into and written in that language's letters. Names the finder returns in the wrong letters are asked for again, then left out.
- **The translator is told to write names in your language**, in its own letters, when the glossary has none.
- **A name kept for two languages** (English and French, Arabic and Persian) no longer loses one of them; each language keeps its own, and switching the language you translate into switches the names. After a switch, names for the new language are looked for (they were not).
- **Pasted lists** are no longer all marked as your current language whatever they hold.
- Nothing of yours is deleted: an entry in the wrong letters stays, marked «not used»; older entries whose language is unknown are shown as «Language not set», with a selector.

### New — Retranslate in the glossary
- A **Retranslate** button on each entry, for the entries you select, and for all entries shown. It opens a box with the instructions sent to the AI — edit them as you like; they are remembered, and can be reset.
- Progress is shown and it can be stopped; an entry keeps its old name until the new one arrives; the whole run can be undone. Only paragraphs holding a changed name are translated again.

### To know
- Translations made before this version may still hold English names: use «Translate the chapter again» for those.
