### Fixes
- **YouTube on a computer saved the YouTube page instead of the video** (it showed 100% at once, and opening it took you to YouTube). Two causes, both fixed:
  - yt-dlp now needs a JavaScript runtime to read YouTube, and the computer's copy had none, so it read nothing. It now uses the app's own Node.
  - When a video could not be read, the link was saved as an ordinary file — the page. A video site's link is never saved as its page now: the video downloader sets itself up the first time such a link is pasted (no extra tap), and if a video still can't be read the app says so and adds nothing.
- **Any link that gives a web page** instead of a file now asks first: look for the files and videos on it, or save the page itself.
- **X GIFs were broken on a computer unless the link was fixupx**: x.com posts went to gallery-dl, which X refuses without an account. Posts now go to the app's X reader, as fixupx links did.
- **The settings' section chips ran off the screen on a computer** and couldn't be scrolled with a mouse; they wrap now. The add-on tabs showed their ids («anime», «tv») when offline; they show their names.

### Computer
- **A new sidebar**: the app's name, «Add a download», each place with its icon and its name, Settings at the foot. Fold it down to icons with its button (remembered); a narrow window folds it by itself.
- **One column per page**: the title, the tabs and the content start at the same edge, in English and Arabic.
- **A new top bar**: a larger title, roomier buttons with a clear hover.

### Downloads
- **A post's photos and videos open only when needed**: a post the video downloader reads (a video, a GIF) keeps its qualities in the add sheet, with the media list one tap away; a photo post opens its media list at once.
