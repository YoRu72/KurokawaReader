### Fixes
- **The installer choice now works and shows.** Choice buttons did not show which option was picked (in the update sheet and on the Translate on screen page), so the choice looked broken. The picked option is now highlighted, and the update sheet confirms your choice. The same choice is also in *Settings → Updates → Install with*: the app's installer, or Android's. Your choice is used for every update.

### New
- **«Kurokawa Installer» in Android's «Open with» list.** When you open an APK (or an .apks, .xapk or .apkm bundle) from a file manager or a browser, *Kurokawa Installer* is offered next to Android's package installer. It opens the file in the app's own installer: what the app is, its parts, its permissions, then installed.
- **Get a new link by itself.** A download started in the app's browser now remembers the way you took to it: the page you started from, and each button you tapped on the way, on any site. A download page whose address changes on every visit still works. When its link runs out (HTTP 401, 403 or 410), that way is gone again — the same pages, the same buttons, a dialog on the same page included — and the new link continues the download from where it stopped. You see the browser do it.
  - *New link from the page* on the download's page now replays that way instead of leaving it to you.
  - Turn on *Get a new link by itself* (on the download's page; off by default) and it happens as soon as the link runs out, up to three times an hour, while the app is open.
  - It needs a download started in the app's browser (on Android). For others, *New link* still takes a pasted link.
