### Fixes — PDF → Word, memory and speed
- **Large books no longer exhaust memory while the Word file is written.** The whole document was held in memory several times over at the end of a conversion; a 1,061-page book needed about 2.2 GB there, enough to make a phone hang without a word. The file is now written page by page: the same book needs about 0.8 GB, and its output is unchanged.
- **Faster on large books**: the font stage no longer searches every line of the book for every font (the 1,061-page book: about 59 s → 53 s on the test machine).
- **Devices with little memory** read the book with fewer workers at once, so they do not run short.
- **Progress keeps moving** while the fonts are built and the pages written; it used to stand at 85% for a long while.
- **Running out of memory now says so**, in place of quietly starting the whole book again by a slower way.
- A picture repeated on many pages is kept once while the book is read.

The converted file is the same as before, part for part.
