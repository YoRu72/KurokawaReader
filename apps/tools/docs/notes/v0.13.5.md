### Fixes
- **Downloads no longer overload slow servers.** A download now starts with a few connections and adds more only while each step makes it faster, as speed-test apps do. A server that refuses extra connections, or gets no faster, keeps the number that worked.

### New
- **Faster downloads on fast connections.** Up to 32 connections per download (24 by default, up from 16). They are added in steps, doubling each time while the speed keeps rising.
- **Faster torrents.**
  - The DHT is found at once on the first start, from several well-known nodes.
  - Uploads go to the peers that send back the most, which keeps them sending to you.
  - Several peers behind one shared address are now all let in.
