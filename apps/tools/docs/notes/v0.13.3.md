### Fixes
- **A download whose link ran out can go on.** Signed links (itch.io, cloud storage) stop working after a while, and the download then failed with «HTTP 403» and could not resume. Its page now explains what happened and offers two ways to continue from where it stopped:
  - *New link from the page* opens the page it came from in the app's browser. The next download you start there is given to this download (with the site's cookies) instead of becoming a new one.
  - *New link* lets you paste a link yourself.
- **Fewer 403 failures with many connections.** Some storage answers «403» to one connection too many while the others carry on. That is now taken as a refusal: the download goes on over the connections that are accepted, instead of failing.
- **Files get their real name from the start.** The name the server gives (or the right extension for the file's type, such as .apk instead of .bin) is now used as soon as the server answers. Before, a file kept the link's name until it finished.
