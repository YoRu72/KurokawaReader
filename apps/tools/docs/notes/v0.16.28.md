### Fixes
- **Windows: a download's files are listed properly again.** Each file was given to the app by its whole path (`C:/Users/…/Show/e1.mkv`) where the app expects its path inside the download's folder (`Show/e1.mkv`). This broke the file tree of a download with several files, choosing which files of a torrent to download, and deleting one episode's file. Paths are now in one form throughout, including after a rename.
- **Wi-Fi share of a torrent with several files** pointed at a path with the torrent's folder twice (`Show/Show/e1.mkv`), so those files could not be sent. Fixed on every system.
