### Fixes
- **Saved translations can be switched on and off without a connection or a key.** A book translated before now shows the translation bar even when no AI translator is set up, or its key was removed. Its first button switches between the translation and the original at any time, from the translations kept on the device. Before, the bar did not appear, and the translate button opened the AI settings instead.
- **No more key prompts over kept translations.** A chapter whose translations are kept no longer asks for an AI key when the translator is not set up; it asks only when nothing of the chapter was kept.
- **Opening a book offline is quicker with the auto glossary on.** The glossary is no longer looked for when there is no connection or no translator, so the kept translations appear at once.
