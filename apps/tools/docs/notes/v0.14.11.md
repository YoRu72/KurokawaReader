### Fixes
- **DoH on made nothing load («ERR_PROXY_CONNECTION_FAILED»).** The web view takes a connection its proxy drops for a proxy that is down and gives up on everything. The proxy no longer drops any: a tunnel that cannot be made is answered with a 502 and the reason goes to the DoH sheet's events; a tunnel once made stays open as long as either side keeps it (it used to be cut after thirty seconds of quiet, which broke the pooled connections the web view reuses); the proxy checks itself through its own port before any web view is pointed at it, and is not used when the check fails; and should the web view still report it unreachable, the app lets go of it at once and loads the page the earlier way (the requests made for the page), telling you so.
- The proxy is started and stopped off the main thread; turning DoH on in the browser reloads the page once the proxy is up.
