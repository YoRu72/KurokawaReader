0.2.1 never reached Android (its build stopped on a library that needs Android 7), so its changes are here too.

### Fixes
- **Android build:** the app now targets Android 7.0 and later, which the video tools need; 0.2.1's phone build had stopped there.
- **Add-on sources failed on the device** — every subtitle and search chip showed a warning. The add-ons' code is fetched from GitHub, which labels it as plain text, and the phone refused to run it; it is now stored as JavaScript (add-ons already installed are fixed on load too).
- Arabic: the schedule's times no longer wrap (24-hour clock), counts and times use one set of digits, «بُثَّت» for aired episodes.
- The downloads page says plainly that nothing has been downloaded yet when the list is empty.
- A page that fails to draw shows what went wrong (and a retry) instead of staying blank.

### New
- **Video links in the same Add bar (yt-dlp):** paste a YouTube link — or one from over a thousand other sites — and the downloader reads the page: title, picture, every quality with its size, audio only, and subtitles in your languages. Pick one and it downloads like any other task; a playlist adds all its videos. It comes as the **Video** add-on, offered right in the Add sheet the first time you paste such a link. yt-dlp is taken from its own GitHub releases and keeps itself up to date (Settings → Video has the version and an «Update yt-dlp» button), with the preferred quality, MP4/MKV/WebM, the cover embedded and sponsor parts skipped.
- **Download details the Prism way:** a task's page shows its pieces as they fill (per connection), a speed chart and a log. Downloads are sorted into categories (video, music, documents, programs, archives, images, subtitles, or your own), each with an optional folder; sort by name, size, state or date; links with ranges such as `[001-100]` add a whole series of files.
- **Layout direction** in Settings: by language, left to right, or right to left — as in the reader.
- **Debrid** add-on: Real-Debrid, AllDebrid, Premiumize and TorBox. A magnet, .torrent or hoster link goes through the service («Through Real-Debrid» in the Add sheet, or by default from Settings → Downloads); the cloud fetches it and the app downloads the files at full speed. A Cloud button on the downloads bar shows the account's transfers.
