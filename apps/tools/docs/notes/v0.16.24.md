### Fixes
- **Google Drive links now download the file.** Before, a shared Drive link downloaded Drive's web page. Large files also stopped at Drive's "can't scan this file for viruses" page instead of downloading.

### Google Drive
- **Folder links**: every file is listed, including files in subfolders. Untick what you don't want. The chosen files are saved inside a folder named after the shared folder, keeping its subfolders. Sizes appear as they're found.
- **Big folders**: a filter box (by name, «.mkv», «1080»…) with "Choose only these", and a count of how many are chosen.
- **File links**: the file's real name and size are shown before you start, and it downloads with several connections and can be resumed. Large files go past Drive's virus-scan page by themselves.
- **Google Docs, Sheets and Slides** download as Word, Excel and PowerPoint files.
- Every kind of Drive link works: file, folder, open, uc, usercontent, links with a resource key, and Workspace links.
- **Clear reasons** when a link isn't shared publicly, when too many people downloaded the file lately (Drive's daily limit), or when the file is gone. When some files of a folder can't be added, the rest still are, and you're told how many were left out.
- **Expired addresses**: when a Drive download fails, it gets a fresh address and continues where it stopped.
- **Links on a page**: the grabber finds Drive links even when they're written as plain text, and lists them under their own Google Drive kind.
- Drive links added from anywhere else (a rule, the clipboard, the app's browser) go the same way.
