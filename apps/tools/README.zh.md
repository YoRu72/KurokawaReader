# Kurokawa Tools

[English](README.md) · [العربية](README.ar.md) · [日本語](README.ja.md) · [한국어](README.ko.md) · [Kurokawa 应用](../../README.md)之一，与 [KurokawaReader](../reader/) 并列

下载、种子、视频网站、动画、字幕、压缩包和播放器，合为一个应用。Android · Windows · macOS · Linux · Web。

- **一个添加栏:** 链接（可多条，或 `[001-100]` 范围）、磁力链接、.torrent 文件、视频网站页面（yt-dlp：画质、仅音频、字幕、播放列表，自动更新）。ZIP 可先看内容再下载。
- **Prism 风格:** 单文件多连接、分块图、速度图、日志、分类与文件夹、计划任务、剪贴板监视、网页链接抓取、校验和比对、用 ffmpeg 转换与压缩体积。
- **种子搜索:** 以封面展示 AniList 与 IMDb 上的作品，按作品归类发布（Knaben、The Pirate Bay、Nyaa、YTS、EZTV、Torrentio）。
- **动画:** AniList 追踪、季度表、放送时间表、按状态的列表；通过内置来源或 **Seanime、Hayase、Stremio 扩展**（应用内市场）查找剧集；区间下载、排除填充集、自动获取新剧集。
- **字幕:** 同时搜索 9 个网站；动画集数对应到 IMDb 的季与集。
- **压缩包（HatchZip 风格）:** 空间预估、ZIP 与 tar 原地解压（可续、可放弃并还原）、测试、先校验、.sfv 检查、拒绝恶意压缩包。
- **应用安装（Android）:** 直接从文件安装 APK 与分包（.apks / .xapk / .apkm）。
- **播放器:** REX Player 手势、A/B 剪辑（烧录字幕）、在线字幕、跳过片头片尾（AniSkip、章节）、画面滤镜、环境光、画中画。

阿拉伯语 · 英语 · 日语 · 韩语 · 中文，RTL/LTR，Material 3 Expressive，默认深色。
