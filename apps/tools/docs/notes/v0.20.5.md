### Fixes
- **A direct link to a file is downloaded as a file.** A link ending in a plain file name (a PDF, a zip, an e-book) used to be handed to the video reader on some sites, which answered «made no file» and the download failed at 0 B. It now goes to the ordinary downloader. If the video reader still ends with no file and the link answers with one, the app tries again as a plain download, once. Names with Arabic letters, spaces and percent signs keep their ending (.pdf, .zip) in sight.
- **Resuming a cut-short file job no longer repeats finished steps.** After the app was closed in the middle of a move, a moved file could meet itself and an empty source folder stayed behind. Undoing a job that was cut after a folder had replaced a file now says plainly that the file was lost.
- **The view button in Files (the four squares) now does something.** It cycles list, grid and gallery and redraws in place.
- **On a computer, the Files list no longer stops at 320 rows** in a folder of thousands, and picking a row no longer throws the list back to the top.
- **Saving a text file keeps its line endings.** Files with Windows line endings used to be saved with Unix ones.
- **Several small leaks are closed:** the page kept adding listeners each time Settings, the discover page or the add sheet was opened.
- **Downloads check the other side's certificate again.** The bundled downloader on a computer had been told to accept any certificate. It now refuses a site whose certificate is not trusted, says so plainly, and offers a button to open the address in your browser.
- **Names are looked up through the resolver you chose.** With DNS over HTTPS on, tracker names, the add-torrent step and downloads no longer slip back to the network's own DNS, and a resolver that filters names is no longer overridden.
- **After you watch a show, the app returns to the show's page** instead of the Downloads page. The cause was the phone restarting the app's window when the player closed; the app now remembers where it was.
- **A download no longer throws you to the Downloads page.** A small progress bar floats above the page; tap it to go to Downloads. Settings has a switch to bring the old behaviour back.
- **Opening a file from another app:** a file ending in .ts is no longer taken for a video, and the torrent filter no longer catches every unknown file type.
- **Archives:** a name with a colon (meeting 10:30.txt) extracts on Linux and macOS; a name that begins with a drive letter is still refused everywhere.
- **Fixed in the details:** the sort menu's raw key text, a cut-off «Extension» field, and numbers in Arabic lists.

### New: Files
- **Folder sizes** are counted when you ask, and kept until the folder changes.
- **List text size** and a **fast scroller** for long lists.
- **Gallery view** beside list and grid; pinch (or Ctrl and the wheel) changes the number of columns.
- **A better text editor:** line numbers, find and replace, character sets (including Windows Arabic), line endings kept as they were, and long files over 5 MB opened read-only by pages.
- **Rename many files at once.** One sheet: a name, numbers in the order you selected the files, a «name . extension» row as in the downloader, a live preview and presets. The job can be undone, even when it stopped halfway.
- **Check after copying.** *Full check* copies into a hidden folder, compares SHA-256, and only then moves into place; a move deletes its source only after that.
- **Compare two files**, and **find duplicate files** in a folder.
- **Open a book in Kurokawa Reader** from Files.
- **A queue for file jobs:** pause, resume, and a clear title for each job.
- **More archive formats on a phone** (read-only), and **7z archives can be made on a computer**.

### New: safer unpacking
- **The app checks an archive before it changes anything:** the method, the names, duplicates, a password and the space left. A name that is unsafe on any system is refused the same way on all of them.
- **When a name already exists you choose** Replace, Skip or Keep both, for this file or for the rest, and the choice can be undone.
- **A cut-short unpacking can be finished or given up** from a shelf, and the archive is restored byte for byte. The first check of the files can be turned off.
- **Known limit in this version:** unpacking *in place* (the archive shrinks while its files come out) and the unpacking shelf trust the archive and the job files beside it more than they should. Use in-place unpacking only on archives from a source you trust; a hardened engine follows in the next update.
- Phones and the new computer build run the name check and the check before any change; the shelf, undo and byte-for-byte restore run in the previous computer build for now.

### New: Kurokawa in «Open with» (phones)
- **Kurokawa Tools appears when another app opens an archive, a folder, a picture, a text or subtitle file, or any file**, each kind with its own switch in Settings. A file it cannot open itself is offered the list of apps; *Open with…* stays in the menu.
- **Choose a default app per file ending.** Text files open in a viewer that reads UTF-8, UTF-16 and Windows Arabic, and goes read-only when it is not sure.

### New: themes and backgrounds
- **The main theme is Material 3 Expressive again** («Expressive 3»), and light-mode users start on a new cool light theme. A theme you chose yourself is never changed; if the old default was changed for you, a message offers Frost back.
- **Animated backgrounds on a computer:** *Frost drift* and *Expressive flow*, off by default, with Full, Reduced and Still. They pause when the window is hidden or the machine saves battery.

### New: DNS over HTTPS
- **A health check picks the resolver that works best**, a fallback chain when one fails, and no silent fallback to the network's DNS: each use shows which resolver answered or why none did, in your language.
- **The same on a computer and on a phone.** Torrent trackers and the bundled downloader go through the chain too.

### New: anime
- **A cover of your own for a show**, from a file or an address, with *Reset*.
- **A note for each episode**, and **reviews**: a note can be sent to AniList as a review (a show review needs 2,200 characters and a score, and the app says so before you send). MAL has no review service, so a note goes to its list comment.
- **The list updates after you watch**, with a small prompt bar and a line timer that offers a review; a review icon next to each episode does the same.
- **Search for subtitles** from a show's Subtitles sheet: the file is fetched with the floating download bar and attached to the show with episodes matched. The same sheet is on TV series (S01E02 matching) and on films.

### Faster
- **The app starts with much less code:** the part loaded before the first screen went from 327.6 KB to about 195 KB, because most of the words are loaded afterwards in your language.
- **Long lists in Downloads, Files and Videos** draw only the rows near the screen.

### What we ask you to try
These parts were built and tested on a computer and need a real phone or a real computer:
- **Open with:** from a chat or a file manager, open an archive, a folder, a picture and a subtitle file with Kurokawa Tools; set a default app for one ending.
- **A cut-short unpacking:** start unpacking a large archive, close the app, open it again and choose Finish; then try Give up.
- **Rename many files** in the order you tick them, then Undo.
- **Anime:** watch an episode in the player and see that the app returns to the show; give a show a cover; send a note; download a subtitle file.
- **DNS over HTTPS** on a phone and on a computer: pick Automatic, then break one resolver and watch the status line.
- **Animated backgrounds** on your computer: Frost drift and Expressive flow, with the window hidden and shown again; check the fan and the battery.
