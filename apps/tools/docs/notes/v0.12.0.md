### Fixes
- **The + menu fits the screen.** With large text or on a short phone its top items went under the status bar. It now scrolls when it is taller than the screen, and the hints are left out on short screens.
- **The Anime tabs no longer touch the screen's edge**, and the Filters button has room under the search box.
- **Extensions:**
  - **Torrentio (anime)** no longer fails on a show without a Kitsu or IMDb id. It says nothing and leaves the show to the other sources.
  - **AnimeTosho** is asked again when it is slow or busy. When it answers with a web page instead of results, it says so plainly. An episode's search now keeps only that episode (and batches holding it), not the whole show.
  - Sources have longer to answer (35 seconds) before they count as failed.
- **The sources' chips line up**, warning or not.
- **The extension browser has room between its parts** (the sources, the search, the filters, the list).

### New
- **A torrent's files, the way a file manager shows them.** On a torrent's page:
  - Folders to walk into and out of.
  - Each file's progress and a box: tick it to download it, clear it to leave it out. A folder's box covers everything in it.
  - A search, Finished / Not finished, and the kinds of file it holds (videos, ebooks, subtitles, images…).
  - Get all shown / Get none shown / Invert.
  - A star for the file wanted first.
  - A finished torrent given more files goes on downloading.
- **Search by another name.** In Anime, a release list shows the name the sources were asked for: change it (or tap one of the show's other titles) and search again. When nothing is found, it says so and offers to search every source. In TV and films, a title can be searched by name too, through the search add-ons.
- **Choose another file of a release while watching** (Hayase's picker). If the file picked for an episode was the wrong one, the player's list button shows every video of the release: play another, and it is fetched first while the one you left stops.
- **Look inside archives.** A downloaded .zip, .cbz, .7z, .rar or tar (or one you pick) opens to browse:
  - Its folders, a search, sorted by name or size.
  - A file opens by itself: taken out to the app's cache, then played in the app or opened by the app for its kind.
  - Tick files or folders to take out only those, or extract everything.
  - Also from a finished archive inside a torrent.
