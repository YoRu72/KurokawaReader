### Fixes
- **The Kurokawa Installer is now inside the reader** — no need for Kurokawa Tools. An update is read as a stream straight into the system's install session; the sheet shows the app's name, version (old → new), size and whether its **signature matches the installed app** before anything is installed, then the copying, the installing, the system's confirmation when it asks, and the outcome in plain words (cancelled, blocked, not enough storage, a conflicting signature…). The system's installer is still there as a choice in Settings.
- Split bundles (`.apks`, `.xapk`, `.apkm`) install too: the parts for this phone (its processor, language and screen) are picked out.

### Smaller app
- **The Android app is about a third smaller.** The code is shrunk by R8 at build; seven reading fonts rarely chosen (EB Garamond, Vollkorn, Source Serif, Bitter, Gelasio, Crimson Pro, TeX Gyre Termes) and pdf.js's CJK character maps are no longer carried in the package: **a font is fetched the first time it is chosen and then kept on the phone**, so it works offline afterwards; the character maps (for Chinese, Japanese and Korean PDFs without embedded fonts) come from the web app when such a PDF is opened. Literata, Merriweather, Lora, Inter, Atkinson and all the Arabic fonts are still in the package. The web app and the desktop apps carry everything as before.

### OTL (web folders)
- **Covers at once:** a series whose AniList cover is known shows it the moment its card appears, and its first volume's own cover takes its place as it is read.
- **A lighter shelf:** sorting hundreds of series uses one collator instead of building one per comparison; a file's name is parsed once, not again for every sort and card; the top shelf is filtered and sorted once per filter rather than once per page; the Newest shelf is found once per index; the filter sheet's genres and tags are counted once per answer from AniList rather than every time it opens.
