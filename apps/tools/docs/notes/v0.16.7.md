### Fixes
- **Player — the subtitle translation test** counted a batch of lines as one request and failed on a computer; the player was right, the test now counts each line.

### Smaller app
- **Android APK 16.4 → about 12 MB** (arm64; universal 29.8 → about 25 MB): yt-dlp now comes with the Python pack, which is what runs it, instead of sitting in every APK; a phone that already has the Python pack gets yt-dlp on its own the first time a video is grabbed. Bouncy Castle's tables for a signature scheme nothing uses are left out.
- **Fonts**: Inter keeps only the letters, weights and features the app draws with (151 → 79 KB); two Arabic fonts nothing used are gone.
- **Styles**: rules no screen of the app could match removed (CSS 259 → 162 KB), every screen checked to look the same pixel for pixel.

### Faster start
- **Ready about a quarter sooner** (479 → 369 ms on a slowed phone): the add sheet and its video panel load on the first tap that opens them, and the scheduler and clipboard watcher no longer pull in the grabber and checksums at start (JS at start 337 → 278 KB).
- A check that every release's APK carries no big leftover file, and the Python pack carries yt-dlp.
