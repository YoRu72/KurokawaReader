## Fixed

- **Arabic shows the digits 0-9 by default.** A choice of ١٢٣ made in Settings is kept.
- **Importing a theme file is safer and clearer.** A file that is not a Kurokawa theme, or one holding values the app does not accept, is refused with a plain message and nothing is added.

## Changed

- **The theme editor keeps text readable:** a saved theme whose text would be too faint has its contrast corrected, and says so.
- **Yellow and orange are not used in the app:** a colour picked in that range moves to the nearest one allowed.
