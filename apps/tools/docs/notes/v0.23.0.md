### New
- **Add-ons, themes and wallpapers arrive by themselves.** Tools looks at its repository when it starts, when you come back to it, and every 6 hours, and updates each add-on on its own; the app itself is updated only when an add-on says it needs a newer one («needs the app update»). One switch under the update settings turns this off; «Check now» and the time of the last check are beside it.
- **Every file is checked before it is used.** Each add-on, theme pack and wallpaper has a published fingerprint; a file that does not match is not installed, the one you have keeps working, and Tools tries again later. An update never goes back to an older version.
- **New themes show up in the theme browser** with a «New» mark, and Appearance gets a small dot when there is something new. Themes made of colours only can now be added to the repository without a new release. Your own themes are never touched.
- **Wallpapers can come from the repository too,** after the built-in ones, with the same check; one that needs a newer engine says so.
- **«Hydro» wallpaper:** still water under a moon, a glimmering path of light, slow light drifting beneath the surface and a little mist. The pointer leaves a wake; a tap drops rings that spread and push the light aside; now and then a drop falls by itself. It follows the theme's colours in dark mode.
- A quiet notice lists what was updated, and the add-ons list shows each add-on's version and when it was updated.
