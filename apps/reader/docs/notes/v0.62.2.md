### Fixes — Back
- **Back always leaves a book.** When the app reopened the book you were last reading at start-up, the phone's Back button and the arrow in the top bar could both do nothing, leaving you locked inside that book until the app was started some other way. Present since 0.61.0; fixed at its cause.
- **The arrow in the top bar leaves at once**, whatever else is open.
- **Back is never ignored twice.** If one press changed nothing, the next closes everything that is open and leaves the view in the same press.
- **Android: a page that stops answering Back is rescued.** If two presses get no answer for four seconds, the app returns to the library by itself and does not reopen the book.
- **Back inside a library folder goes up to the main page** instead of offering to leave the app. One level per press: selection, then search, then series, then folder, then tag or shelf, then the main page — and each level returns to where you had scrolled. "Press Back again to leave" now appears only on the library's main page.
- Back in Settings first clears the settings search.

### Performance report
- Records every Back that was held or had no effect, and every rescue, so a fault of this kind can be read from a report.
