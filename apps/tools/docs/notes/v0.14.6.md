### Player
- **Clips with the player's font and style**: when a clip is cut with the subtitles burnt in, a new switch keeps the font, size, colours and outline exactly as the player shows them, and the font file itself travels with the clip so the burnt text uses it (an ASS's own fonts are gathered the same way).
- **Saved frames carry the subtitle** on screen, drawn in the player's style (a switch in the frame tool).
