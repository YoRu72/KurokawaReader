### Fixes — PDF → Word, wrong letters and marks (Arabic)
- **Letters replaced by a haraka inside ligatures.** Where a PDF's own text map named a two-letter ligature as one letter and a mark, the second letter was lost: «جملة» came out as «جُلة», «يحذف» as «يُذف», «جميع» as «جُيع». The missing letter is now recovered from the font's own ligatures.
- **Fatha read as kasra.** Some fonts draw the fatha from below the line; it was taken for a kasra («وَأْمُرْ» came out as «وِأْمُرْ», «عَصَاكَ» as «عِصِاكِ»). A mark is now judged by where its ink stands.
- **Harakat on the wrong letter**, most seen with coloured marks: «عَلَى» came out as «علََى». Each mark now goes to the letter it stands over.
- **The same haraka written twice** on one letter is written once.
- **Numbers drawn in two pieces came out in the wrong order**: «١٤٤٣» was written «٣١٤٤»; verse and page numbers too. Groups set apart (a telephone number's) stay apart.
- **Persian letters in Arabic words**: «السامية» was written with ی (and ه with ھ). The PDF's own letter is kept.

### Known, not yet fixed
- A few rare ligatures that the font gives no way to settle keep the PDF's own text.
- Lost spaces between words and lines merged into one paragraph are the next pieces of this work.
