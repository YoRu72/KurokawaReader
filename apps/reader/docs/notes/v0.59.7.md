### Fixes
- **PDF → Word on design-tool PDFs** (Canva, Figma and the like):
  - Titles set with wide letter spacing come out as one word with that spacing, not as letters parted by spaces that then wrap.
  - Text set at an angle — a diagonal stamp, a label up the side of a poster — comes out as a turned text box in Word, at its place and angle, instead of lying flat where it started. (LibreOffice shows these boxes unturned; Word turns them.)
  - Text drawn glyph by glyph, overlapping layers and full-page background pictures were already handled; a test PDF of all of these now lives with the converter's test corpus.
- Dead code removed.
